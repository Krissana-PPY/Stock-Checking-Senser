# **YS-DIV268N-5A Stepper Motor Driver**

**Model:** *YS-DIV268N-5A*

---

The YS-DIV268N-5A is a driver designed for controlling two-phase hybrid stepper motors. It converts control signals from microcontrollers (such as Arduino or ESP32) into suitable electrical signals for driving stepper motors, enabling precise control of rotation, direction, and speed. This driver is specifically designed for two-phase hybrid stepper motors.
