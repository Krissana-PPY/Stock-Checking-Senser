# **MPU6050 Gyroscope and Accelerometer**

**Model:** *MPU6050*

---

The MPU6050 is a 6-axis motion tracking device that detects and processes movement data, including both acceleration and rotation. It enables calculation of tilt (pitch, roll) and heading (yaw) of an object. The chip integrates two main sensors:

- **3-axis Gyroscope:** Measures angular velocity along the X, Y, and Z axes, allowing detection of rotational direction and speed.
- **3-axis Accelerometer:** Measures acceleration along the X, Y, and Z axes, enabling detection of changes in speed or tilt under gravity.
